# 光学尺寸链与四模态合焦检查

> T03 工作文档。所有参数值、状态和后续修改以 [望远镜参数表](2026-11-06_望远镜参数表.md) 为准；坐标与物理基准见 [总体基准与派生尺寸链](2026-11-06_总体基准与派生尺寸链.md)。本轮的“通过”指名义尺寸和机械行程计算通过，不替代 T01 实测或 T08d 实物合焦试验。

## 1. 主镜—副镜—焦平面基准

主镜顶点 `G0` 到副镜中心 `S` 采用当前光学布局工作值：

```text
primary_to_sec_dist = 1121 mm  （G-01，工程默认）
```

无巴洛时，主镜固有焦平面位于副镜后：

```text
sec_to_native_focal_plane
= primary_mirror_focal − primary_to_sec_dist
= 1300 − 1121
= 179 mm  （O-43）
```

**固有焦平面与巴洛后焦平面必须分开。** O-06 的 226.75 mm 是“巴洛镜＋行星相机”基准光程，包含巴洛作用，不能代入上式反推 G-01。T02 曾采用 `1300−226.75=1073.25 mm`，T03 已显式纠正该假设并同步更新总体骨架。

修正后总体骨架的关键坐标为：

```text
S  = 1121 mm
U0 = -8 + 1197.7772 = 1189.7772 mm
G-02 = U0 − S = 68.7772 mm
```

## 2. 调焦座光程公式

沿调焦轴 `+X`，从副镜中心到设备焦点的距离统一写为：

```text
b = R + h + L + d
```

| 符号 | 含义 | 当前来源 |
| --- | --- | --- |
| `b` | 副镜中心到当前设备场栏／传感器的轴向光程 | 各模式派生 |
| `R` | 主镜光轴到调焦座安装面 `F0` 的距离 | O-05＝118.75 mm |
| `h` | 调焦座安装面到 1.25 英寸接口肩面的高度 | 46～56 mm |
| `L` | 额外延长筒的有效总长度 | 各模式派生 |
| `d` | 设备场栏／传感器相对接口肩面的偏移 | 外侧为正、内侧为负 |

旧矩阵没有显式列出 `d`，因此不能只用 `R＋h＋L` 复算。反推出的设备偏移为：

| 设备或组合 | 工作偏移 | 状态与用途 |
| --- | ---: | --- |
| 广角目镜场栏 | −27 mm（O-19） | 工程默认，待 FM-11／FM-12 复核 |
| 相机传感器 | −23 mm（O-20） | 工程默认，待 FM-09／FM-10 复核 |
| 目视巴洛附加偏移 | ＋50 mm（O-21） | 随巴洛选型变化 |
| 巴洛＋相机设备总光程 | ＋57 mm（O-22） | 由 226.75−118.75−51 派生，是选型目标而非实物规格 |

## 4. 调焦行程结论

四种组合的当前名义高度都落在 46～56 mm 内，因此**算术行程检查通过**。其中：

- 最小余量是广角目视低端的 **1.25 mm**，其次是相机直插低端的 **2.25 mm**；
- 目视巴洛高端余量为 3 mm；
- 巴洛＋相机基准两端各 5 mm。

这些余量尚未扣除实物接口偏差、目镜场栏差异、热胀和装配误差，不能解释为“全天候已验证”。尤其 O-19／O-20 都来自旧矩阵反推，应优先用厂家数据或实物试装替换。

对基准巴洛＋相机组合，在不增加额外延长筒时，57 mm 设备光程位于行程中点；整个 46～56 mm 行程对应的可接受设备光程为：

```text
L_accessory = 226.75 − 118.75 − h
h = 46～56  →  L_accessory = 52～62 mm
```

因此巴洛选型时，可先检查“巴洛＋相机＋IRCUT”的等效光程是否能落在 **52～62 mm**；不能落在此范围时再重算延长筒或 O-06，而不是硬改主镜—副镜间距。

## 5. 副镜适配检查

副镜位于巴洛之前，轴上锥形光束按主镜固有焦平面 179 mm 计算：

```text
secondary_axial_beam_d
= primary_mirror_d × sec_to_native_focal_plane / primary_mirror_focal
= 160 × 179 / 1300
= 22.0308 mm
```

现有副镜短轴 35 mm 对应：

- 轴上光束直径余量：`35−22.0308=12.9692 mm`，单边约 6.48 mm；
- 45° 椭圆长轴：`35/cos(45°)=49.4975 mm`；
- 直径遮挡比：`35/160=21.875%`；
- 面积遮挡比：`(35/160)²=4.785%`，不含蜘蛛架叶片。

**结论：35 mm 短轴对轴上光束有充分名义余量，副镜几何适配通过初步检查。** 但离轴全视场是否无渐晕仍需目镜场栏直径、副镜偏心量和调角余量；副镜座轴向包络及蜘蛛架冲突由 T01 实测和 T12 继续检查。本结论不等同于全视场成像验收。
