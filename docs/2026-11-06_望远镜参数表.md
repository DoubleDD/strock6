# 道布森开放式桁架望远镜参数表

> **本表是当前设计参数的唯一维护入口。** 所有参数审核、修改和状态确认均以本表为准；wiki、历史说明文档和既有 FCStd 中的数值仅作参考。已确认参数需要变更时，也应先修改本表并检查下游影响。

## 状态与填写规则

- `已确认`：已有实物、明确决策或本轮确认的光学基准，可作为当前设计输入。
- `待实测`：需要测量实物后填写或确认。
- `待定`：旧候选值或方案假设，尚未确认，不得直接作为最终制造依据。
- `派生`：由其他参数计算，不单独修改；其可靠性取决于上游参数状态。
- `工程默认`：实测或审核完成前，明确选定用于建模和计算的工作值（通常取自候选值或有依据的估算）。仅用于推进设计，**不得作为最终加工依据**；被实测或审核结论取代时显式改状态并在备注记录。与 `待定` 的区别：`待定` 是候选未选，`工程默认` 是已选定工作值。
- 审核时可直接修改“值／候选值”和“状态”，并在备注中记录依据。参数 ID 应保持稳定，便于后续模型和文档引用。
- **参数组织原则**：基础输入只设两类——①已有实物实测尺寸（H／O 节）；②用户可直观判断的工艺量（板厚 M-01、最小壁宽 R-09、装配间隙 M-04／M-11 等，用手比划即有概念的量）。其余一切结构尺寸（环径、环距、箱体外廓等）一律由这两类经派生链推出，**不要求用户直接确认抽象总体尺寸**；上游工艺量变更时派生值自动重算。
- **参数类型列**：`基础`＝直接设定的值（实测、决策或规则定义）；`派生`＝由其他参数经公式或引用计算得出，值不手改、随上游自动重算。类型与状态相互独立——如 R-02 类型为派生、状态为已确认，表示『统一引用 M-01』这一规则已获确认。
- **命名规则**：英文参数名一律用小写下划线全词（如 `oct_ring_d`），不用拼音缩写（如 bjh）和晦涩简写；直径 `_d`、外径 `_od`、内径 `_id`、厚度 `thick`、间隙 `gap` 为固定后缀。历史更名在备注中说明。
- 除明确列出的例外外，**所有木板件统一引用 `M-01 board_thick`，不得另设板厚真值**。
- **闭合圆、圆环、圆孔和圆杆以直径表示**，优先使用 `*_d`、`*_od`、`*_id` 命名；如模型需要半径，则通过 `r = d / 2` 派生。**未闭合圆弧直接使用半径表示**，以 `R` 或 `*_r` 标注，不换算成直径。光学距离等非圆尺寸不适用此规则。

## 六、功能与接口要求

这些要求不提供数值真值，但会约束后续参数的选择：

- 支持广角目镜、目镜＋巴洛镜、巴洛镜＋行星相机、行星相机直插四种组合。
- 安装寻星镜、导星设备和遮光罩；其型号、包络、质量与接口待定。
- 当前手动使用，未来预留 GoTo 和赤道平台接口。
- 不借助工具完成拆装。
- 除铝杆外，其余部分装入底座箱；暂无已确认箱体尺寸和整机质量上限，设计优先考虑紧凑。
- 主要采用木工 CNC 和手工打孔；金属结构件主要为已有铝杆及上环接头，螺钉等标准件可采购成品。
