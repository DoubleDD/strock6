# 项目概览

**strock6** 是一台 Strock 风格超轻桁架式便携牛顿反望远镜的 FreeCAD 3D 设计工程。光学系统为 160 mm f/8.125（焦距 1300 mm）球面主镜 + 八角环桁架结构（无镜筒），要求紧凑、免工具拆装，并将除铝杆外的部分收纳入底座箱。当前需求与旧结构尺寸的审核状态见 [需求与旧尺寸审核](需求与参数审核.md)。

## 系统构成

- **光学**：Ø160 主镜（f=1300）、副镜、四模态合焦体系（目镜 / 目镜+巴洛 / 巴洛+行星相机 / 相机直插），详见 [光学合焦与调焦座参数](../optics/光学合焦与调焦座参数.md)；旧模型中的主镜厚度等待实测审核
- **结构模块**：底座（摇架箱 + 俯仰轴承）、主镜座支撑（两个八角环直接套合主镜自带镜座，无独立主镜箱）、桁架（Ø12 铝杆直接连接八角环）、顶环与副镜（上环 + 调焦座 + 副镜座）
- **尺寸契约**：所有跨模块尺寸集中在 `cad/interfaces/Interfaces.FCStd`，详见 [Interfaces 契约层](../contract/接口契约层.md)

## 目录与模块划分

| 目录 | 角色 |
| --- | --- |
| `cad/00_TotalAssembly/` | 总装配（待建，各模块组装图以 App::Link 汇入） |
| `cad/01_Base/` | 底座模块：`BaseAssembly` 组装图 + `AltitudeBearing/` 俯仰轴承小模块 |
| `cad/02_PrimarySupport/` | 主镜座支撑模块：双八角环直接套合主镜自带镜座（2026-11-06 由 `02_MirrorBox` 改名） |
| `cad/03_Truss/` | 桁架模块 |
| `cad/04_TopEnd/` | 顶环与副镜模块：`Secondary/`、`UpperRing/` 两个小模块 |
| `cad/05_EquatorialPlatform/` `cad/06_GoTo/` | 赤道平台 / GoTo（规划中，未建模） |
| `cad/99_CommonParts/` | 跨模块通用件 |
| `cad/interfaces/` | 契约层 |
| `src/` | 工具与自动化源码 |
| `tests/` | 自动化测试；测试专用模型位于 `tests/fixtures/cad/` |

词汇体系：目录名 = 角色英文直译，弃用 Master/LTA/UTA 等与实际结构不符的黑话（本设计无镜筒），改名映射见 [raw 记录](../../raw/project/2026-11-06_目录与文件改名映射.md)。`MirrorBox` 为历史名称，已于 2026-11-06 改名为 `02_PrimarySupport/`（目录、链接与 XLink 已同步处理）。
