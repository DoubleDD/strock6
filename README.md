# strock6

道布森开放式桁架望远镜的参数化设计仓库，包含 FreeCAD 模型、自动化工具、测试、制造导出和设计文档。

## 目录入口

- `cad/`：正式产品模型、模块装配、公共件和跨模块契约。
- `src/`：工具与自动化源码。
- `tests/`：自动化测试；测试专用模型位于 `tests/fixtures/cad/`。
- `exports/`：统一交付输出，按 STEP、STL、BOM 和工程图分类。
- `docs/`：当前设计参数、实施计划和工作文档。
- `TODO/`：需要人工测量、采购、试装或确认的事项。
- `wiki/`：整理后的知识说明与导航。
- `raw/`：历史来源快照，原则上只读。
- `backup/`：本地自动备份，不进入 Git。
