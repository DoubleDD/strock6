# strock6 · Ø160 f/8.125 便携式桁架道布森望远镜

一台可拆解、可装箱、免工具装配的 Strock 风格超轻桁架牛顿反射望远镜——从**参数表 → FreeCAD 模型 → CNC 图纸**的完整参数化设计工程。

> **当前为设计阶段，不是生产版本。** 大量尺寸仍是 `工程默认` 或 `待实测`，实物试切、试装与观测均未执行；在参数表中对应项升级为 `已确认` 之前，任何数值都不得直接用于加工。

## 项目简介

本项目用 FreeCAD 完整设计一台道布森式开放式桁架望远镜：主镜自带镜座，由两个八角环直接套合支撑（**没有独立主镜箱**），8 根铝杆直接连到八角环，整机可拆解收纳进底座箱。设计采用**参数驱动、模块解耦、跨会话渐进验证**：所有尺寸先在参数表裁决，再经跨模块契约层分发到模型与图纸，避免模型之间互相抄数。

## 设计特点

- **单一参数真值**：`docs/2026-11-06_望远镜参数表.md` 是唯一人工维护入口；模型、图纸、文档都从它派生，不接受任一侧的静默偏离。
- **模块解耦 + 契约层**：跨模块尺寸统一经 `cad/91_Interfaces/Interfaces.FCStd` 的 `if_*` 别名分发，模块之间不直接引用对方生成面或生成边。
- **模型语义化**：零件、Body、草图、约束的 `Label` 与尺寸名全部使用自描述中文，模型树可直接当图纸读。
- **可制造性内建**：木工 CNC 容差分档、榫槽宽度、螺栓过孔、整板排版、小件连接桥都写进参数和交付图形，而不是事后补图。
- **未知即未知**：不存在的结构（主镜箱、已选型巴洛、GoTo 机构）不建模、不编尺寸；GoTo 与赤道平台只冻结必要接口边界。

## 快速开始

### 1. 克隆（FCStd / STEP / STL 走 Git LFS）

```bash
git lfs install
git clone git@github.com:DoubleDD/strock6.git
cd strock6
```

### 2. 打开模型

用 FreeCAD 1.1.4 打开整机总装：

```text
cad/00_TotalAssembly/TotalAssembly.FCStd
```

各模块可单独打开：`01_Dob/DobAssembly.FCStd`、`02_PrimarySupport/PrimarySupportAssembly.FCStd`、`03_Truss/TrussAssembly.FCStd`、`04_TopEnd/` 下的子总成（`*_Asm4.FCStd` 为 Assembly4 并行验证装配）。总装只通过 `App::Link` 引用源件，不在总装里绘制新零件。

### 3. 命令行与脚本

```bash
# macOS 默认安装路径
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd --version

# 批量修正模型默认可见性（需在 FreeCAD GUI 中运行后保存重开验证）
# src/tools/freecad_set_default_visibility.py

# 备份监控
# src/tools/freecad_backup_monitor.py

# 方位/俯仰联动演示面板
# src/freecad/dob_motion_panel.py
```

- `ty.toml` 已把类型检查环境指向 FreeCAD 内置 Python，便于脚本静态检查。
- `tests/fixtures/cad/` 存放只服务于验证的模型；正式产品模型不进测试目录。

## 设计纪律（不可逾越的红线）

1. **绝不编造尺寸**：未知值保持 `待定` / `待实测` / 变量或范围，不为让模型闭合而虚构数值，也不把历史快照当成当前需求。
2. **唯一真值入口**：参数表未更新并经用户确认前，不单方面修改契约层或模型，不做自动双向同步。
3. **不擅自改模型/重命名**：用户未明确要求时，不改动 `.FCStd` 等二进制文件，不为“整理”重建历史模型。
4. **零虚构完成度**：未实际重算与测试的内容不得标为已完成；需实物验证的一律标 `待验证` 并登记到 `TODO/`。

修改模型前请先阅读 [AGENTS.md](AGENTS.md) 与项目技能 `.agents/skills/freecad-modeling/SKILL.md`。
