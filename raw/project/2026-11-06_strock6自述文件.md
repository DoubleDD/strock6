# Telescope_Project / strock6

Strock 风格超轻桁架式（Truss Tube）道布森望远镜的 FreeCAD 3D 设计工程。总装配与各子模块以独立 FCStd 文档组织，通过外链（App::Link）组装。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `00_Master/` | 总装配（待建：各模块以 App::Link 汇入） |
| `01_Base/` | 底座模块：`Dob_Base` 组装图（摇架/盖子/PTFE 垫块总成）+ `AltitudeBearing/` 俯仰轴承小模块 |
| `02_LTA/` | 主镜箱模块（Lower Tube Assembly）：`PrimaryCellAssembly` 主镜室与主镜（Ø160 f=1300） |
| `03_Truss/` | 桁架模块：`TrussAssembly` 桁架铝杆与 T 型接头 |
| `04_UTA/` | 顶环与副镜模块（Upper Tube Assembly）：`Secondary/` 副镜座 + `UpperRing/` 上环与调焦座（两个小模块） |
| `05_EqPlatform/` | 赤道跟踪平台模块（EQ Platform，置于底座之下） |
| `06_GoTo/` | GoTo 系统模块（步进电机、传动与支架等） |
| `99_Parts/` | 鱼眼轴承、特氟龙滑块等通用件 |
| `interfaces/` | 跨模块尺寸契约文档（`Interfaces.FCStd`，非模型，模块唯一引用源） |
| `exports/` | 导出的 DXF / STL / STEP（用 3D Viewer 快速预览） |
| `docs/` | 光学焦平面计算表、重心计算草稿 |

## 命名与文档规范

文档层级镜像产品树（BOM 树）：**每个零件一份零件图，每个模块（含小模块）一份组装图，组装图只做 App::Link 装配不画新几何**。

- **零件图**：`<PartName>.FCStd`，一个文件只画一个零件（源件），多处使用用 App::Link 实例化，PascalCase 命名（如 `RockerBase.FCStd`、`OctRing_A.FCStd`）
- **组装图**：`<Module>Assembly.FCStd`，放在模块目录根部（如 `TrussAssembly.FCStd`）
- **小模块**：子目录 `<SubModule>/`，目录名 = 其组装图文件名去掉 `Assembly` 后缀；内部重复同一模式（组装图 + 独有零件图）
- **每个节点目录只放它独有的零件**；跨模块通用件放 `99_Parts/`
- **过渡态说明**：现有 5 份模块文档为"零件体 + 装配体混合"的过渡态（历史文件），保持现状使用；今后新零件一律单独建档、组装图以 Link 引用，逐步演进到纯规范形态

## 工作流约定

- 装配关系用 FreeCAD 的 **App::Link** + Assembly 表达，子模块不要直接复制实体进总装配。
- 每个模块的零件先在各自目录建模，再挂到子装配，最后链入 `00_Master`。
- 导出文件统一放 `exports/`，文件名带模块前缀（如 `01_Base_GroundBoard.dxf`）。
- `.gitignore` 已忽略 FreeCAD 备份/锁文件；`*.FCStd / *.step / *.stl` 走 Git LFS。
- 模块间接口尺寸统一走 `interfaces/Interfaces.FCStd` 契约文档（`if_*` 命名项）。各模块参数表按**相对路径**（`../interfaces/…` 或 `../../interfaces/…`，取决于层级）引用它——文件移动或层级变化后必须重连引用；改契约值只改这一处。

## VS Code 快捷任务

`⌘⇧B` / Terminal → Run Task：

- **FreeCAD: 打开底座总成** — 直接打开 `01_Base/Dob_Base.FCStd`
- **FreeCAD: 启动（空文档）**
- **导出目录: 在 Finder 中预览**

## 装配顺序（草稿）

1. **底座**：`GroundBoard`（地面板）→ 铺特氟龙滑块 → 落 `Sub_Base`（摇臂/方位轴）
2. **LTA 主镜箱**：镜箱体 → 主镜 + 镜室 → 与底座高度轴（枢纽螺栓）连接
3. **桁架**：LTA 顶面 8 根桁架杆，鱼眼轴承两端固定
4. **UTA 顶环**：顶环 + 副镜架 + 调焦座，桁架杆上端连接
5. **总装**：链入 `00_Master`，校核光轴与重心，出焦平面位置
