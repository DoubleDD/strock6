# FreeCAD 结构建模强制规范

本技能是**操作指令层**：告诉 AI 在本项目建模时**必须做什么、禁止做什么**。
理论与"为什么"见 `wiki/methodology/结构设计与FreeCAD建模指南.md`（用户方法论原文快照在 `raw/methodology/2026-11-06_结构设计与FreeCAD建模指南.md`）。
FreeCAD Python API 与脚本写法见用户级技能 `freecad-scripts`。两者与本技能配合使用。
开工前的文档阅读顺序、参数状态语义（已确认/待定/待实测/派生）与禁止编造尺寸等输入纪律，由 `AGENTS.md` 规定，本技能不复述。

核心立场：**结构设计不是"画出形状"，而是在物理边界、载荷、装配和制造约束下求解空间与参数。** CAD 几何成立 ≠ 可制造、可装配、满足强度刚度。

**复用说明**：标注〔项目特定〕的章节承载本项目事实，复用到其他项目时整体替换为目标项目的内容；其余章节为通用规范。参数表、契约层、wiki 等项目内路径以宿主项目的 `AGENTS.md` 为准，本技能不重复登记。

## 1. 参数三层制（唯一真值架构）

建模所用数值按来源取用：已确认参数 → 参数表；跨模块尺寸 → 契约层 `if_*`；模块私有 → 本模块 `Params` 表。

| 层级 | 位置 | 管理范围 | 规则 |
| --- | --- | --- | --- |
| 契约层 | `cad/interfaces/Interfaces.FCStd` | 跨模块共享的 `if_*` 尺寸 | 唯一真值源；模块以相对路径 XLink 引用（一级 `../interfaces/`，二级 `../../interfaces/`） |
| 模块层 | 各模块 `Params` 表 | 模块私有尺寸 + 对本模块契约项的引用 | 不复制契约数值另立真值 |
| 特征级 | 特征属性、命名草图约束 | 不影响其他模块的局部尺寸 | 不必塞入全局表 |

- 跨模块尺寸**只允许**走契约层；禁止在模块表复制独立数值，禁止绕过契约层另建跨模块总尺寸。
- 所有木板件统一引用参数表全局 `board_thick`，不得另设局部板厚真值。
- 闭合圆、圆环、圆孔、圆杆用**直径**表示，模型所需半径由直径派生；未闭合圆弧直接用半径。
- Spreadsheet 参数必须设 Alias 并以表达式引用；保留单位；派生尺寸用公式，禁止重复录入、循环引用。
- 契约回写时机：仅当参数表中的决策已确认、且用户要求回写时才修改 `Interfaces.FCStd`；改后须重连/核对接线并检查全部下游。

### 参数调试、回收与发布

**正向发布**用于正式决策：`用户确认并更新参数表 → 用户要求回写 → AI 更新契约和模型 → 下游回归`。不得把参数表、契约或模型设置为未经用户要求的自动双向同步。

**逆向回收**用于模型内试参，必须按以下步骤执行：

1. **记录基线**：试参前记录目标文档、Sheet、Alias、原值、单位和参数状态；优先在模块私有 `Params` 中试验。调试契约项时先说明下游影响，不将实验值当作已发布接口。
2. **局部验证**：调试后检查 recompute、特征错误、草图解、有效实体和局部接口；未通过的实验不得进入发布。
3. **生成差异清单**：列出原值、实验值、单位、参数类型、验证证据和受影响模块，不直接覆盖参数表或契约。区分模块私有、跨模块和派生参数；派生结果不独立回收，只回收其上游输入。
4. **检查并发冲突**：比较原基线、实验值和当前全局值。若全局值在调试期间已改变，停止自动回收并交用户裁决。
5. **用户裁决**：仅将用户明确采用的实验值写入参数表，记录依据和验证边界。模型重算通过不等于实物验证通过，不得仅凭此升级为 `已确认`。
6. **正式发布**：用户要求回写后，更新必要契约项和下游模型，执行 XLink、草图、实体、接口、干涉及关键参数回归，再按需更新导出物和记录。
7. **放弃实验**：用户不采纳或调试失败时，不发布实验值；需要恢复时仅回退本次实验改动，不覆盖并发修改。

## 2. 当前结构边界（不得违反的设计事实）〔项目特定〕

- 主镜自带镜座，由**两个八角环直接套合**支撑。
- 桁架杆（Ø12 铝杆）**直接安装到八角环**，不设独立主镜箱。
- 无镜筒结构；不得引入 LTA/UTA 等与实况不符的词汇或几何。
- 手动道布森；GoTo / 赤道平台仅预留接口，**不虚构其未知尺寸**。
- 主镜座支撑模块目录为 `cad/02_PrimarySupport/`（原 `02_MirrorBox`，2026-11-06 改名）；`MirrorBox` 旧名仅留存于历史快照，不代表当前存在主镜箱。
- 不主动重命名目录或 FCStd；确需改名必须同步处理 App::Link、XLink、文档与参数引用。

## 3. 文档与装配组织

- 正式产品模型统一位于 `cad/`；工具和自动化源码位于 `src/`；自动化测试位于 `tests/`，测试专用模型位于 `tests/fixtures/cad/`。
- 正式总装和模块装配属于产品定义，留在 `cad/`；只有专为验证建立的测试装配才进入测试目录。
- 目录树镜像产品树：每个零件一份零件图 `<PartName>.FCStd`，每个模块一份组装图 `<Module>Assembly.FCStd`。
- 一个 PartDesign Body 只表示一个单一连续固体；独立零件分别建模。
- 模型树中所有对象的 `Label`（包括零件、Body、装配链接、基准、草图和特征）必须使用中文并自描述，能直接识别对象及其用途；不得使用无语义默认名或晦涩缩写。FCStd 文件名、内部 `Name` 和参数 `Alias` 仍按各自规则维护。
- **组装图只做 `App::Link` 引用源件，不在组装图中绘制新零件几何。**
- 跨模块通用件进 `cad/99_CommonParts/`；外购件只建示意模型并标注"外购·示意"。
- 布尔运算用于几何构造，不等于装配；需要独立制造/更换/运动的零件不得布尔合并。
- 历史"零件体+装配体混合"文档保持现状逐步演进，**不为形式一致而一次性重建**。
- 小模块 = 子目录，目录名 = 组装图名去 `Assembly` 后缀。

## 4. 建模操作规则

**建立顺序（新模块）**：契约接口 → 本模块基准/骨架（Datum、主控草图）→ 零件。

- **骨架驱动**：先建轴心距、配合轴线、回转中心、关键轮廓等主控几何，零件附着稳定基准；修改后必须检查模型错误、接口与干涉，不得假设自动更新必然正确。
- **TNP 规避**：反复修改的草图优先附着原点平面或 Datum Plane；谨慎引用生成面/生成边；跨 Body 引用控制依赖范围、避免循环；装饰性 Fillet/Chamfer 放特征树后段；**Draft 是拔模，不是 Chamfer**。
- **Sketcher**：驱动关键实体的草图尽量完全约束并确认无冲突/冗余；优先几何约束（重合/水平/垂直/平行/对称/相切），少量尺寸定大小位置；命名约束（尺寸标注名称）必须使用自描述中文，改名时同步更新表达式引用；改参后检查草图是否跳到非预期解。
- **特征选择**：回转优先 Revolve；重复孔槽用 Pattern；对称用 Mirrored；孔用 Hole 保留规格；螺纹默认保留工程属性，确有几何需求才建真实螺旋；特征顺序表达依赖关系而非固定模板。
- **未知尺寸收敛**：区分已知约束/工程假设/待验证候选/已验证定值；先定范围、关系、公式，再探索数值；先粗后细（主控尺寸→细节）；每轮只改少数变量并固定评价指标（包络、质量、刚度、焦点位置、间隙）；保留候选记录；**验证后才冻结**，被新证据推翻时显式重开决策，不在局部零件悄悄改出冲突尺寸。
- **检查清单（每次重要变更后）**：recompute 无错误；Body 为有效实体；草图无冲突冗余；接口对齐；静态干涉与运动包络分别检查；运动行程与限位正确。
- **参数回归**：在合理范围内修改主要参数重新计算，确认无特征错误、意外草图解、接口失效。

## 5. 设计与制造约束

- **基准与公差**：功能/装配/加工/检测基准尽量统一；关键尺寸从基准出发检查误差累积；定位不靠螺钉杆。**间隙只负责装入，定位由端面、定位点和夹紧结构承担**；禁止"所有配合面都留 Gap"的通则化。
- **力流**：力流路径直接；弯矩尽量化为拉压（桁架/箱形）；区分强度/刚度/屈曲/共振/疲劳；截面突变处过渡，开孔检查剩余截面与边距。桁架杆以轴向为主但杆端偏心可引入弯曲，不得当纯拉压；弧臂开孔与环减重后检查关键截面。
- **CNC 切板**：一次走刀、整板雕刻；内角受刀具半径限制；大件切透可脱落，**小件必须通过连接桥保持连接**；连接桥尺寸/位置/数量未确认前保持待定；高风险接口经试切/试装/配重试验验证。
- **FDM 打印**：考虑悬垂（约 45° 经验起点）、层间各向异性、收缩翘曲；±0.2～0.3 mm 仅为部分 FDM 经验值。
- **装配**：预留扳手/螺丝刀空间与操作视线；防呆采用非对称、限位特征；验证实际装配顺序；标准件优先，避免无必要特殊规格。

## 6. 交付、版本与汇报

- 导出统一放 `exports/`，文件名带模块前缀（如 `01_Base_BaseAssembly.step`）。
- 交付物按用途选 TechDraw 工程图 / BOM / STEP / DXF / STL，明确材料、数量、公差、表面处理；**CNC 图纸必须体现整板排版与小件连接桥**，不得只交独立零件轮廓。
- 导出后重新导入或用下游工具检查单位、比例、实体/网格有效性和关键尺寸。
- 首件或试装配结果回写参数表与规则（`待验证` 状态跟踪）。
- `*.FCStd / *.step / *.stl` 走 Git LFS（FCStd 加 `lockable`）；备份/锁文件已 gitignore。
- 每次建模工作结束必须说明：实际完成内容、任务状态更新、验证结果（recompute/实体/草图/接口/干涉/参数回归）、阻塞项、下一可执行任务。未实际验证的内容标 `待验证`，不得报完成。
